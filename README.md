# 🛒 E-Commerce Web Application

A full-stack e-commerce web application built for college project evaluation, featuring a Node.js backend and an interactive frontend.

## 🚀 Features
- Dynamic product listing fetched from a REST API.
- Interactive shopping cart counter.
- Simulated checkout system with order confirmation alerts.
- Responsive UI design.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Node.js, Express.js, CORS
